# 📢 마비모 알림봇 개발

## 1. 프로젝트 개요

마비노기 모바일 공식 홈페이지의 주요 게시판을 주기적으로 탐색하여
신규 게시글을 감지하고, 요약 후 길드 디스코드 서버에 자동으로 알림을 전송하는 봇을 개발한다.

---

## 2. 목표

- 공식 홈페이지의 주요 소식 자동 수집
- 신규 게시글 빠른 감지
- 길드원들이 빠르게 확인할 수 있도록 요약 제공
- 디스코드 자동 알림 시스템 구축

---

## 3. MVP 범위

### 3.1 대상 게시판

- 공지사항
- 업데이트
- 이벤트

> ❌ 제외 (초기 MVP)
> 
> - 에린노트
> - 확인중인 현상

---

### 3.2 핵심 기능

### 1) 게시판 목록 크롤링

- 각 게시판 목록 페이지 요청
- 최신 글 N개(5~10개) 수집

---

### 2) 신규 게시글 감지

- 기준: URL 또는 게시글 ID
- 기존 저장 데이터와 비교하여 신규 여부 판단

---

### 3) 상세 본문 수집

- 신규 게시글만 상세 페이지 요청
- HTML → 텍스트 변환

---

### 4) 간단 요약 (초기 버전)

- 본문 상위 3~5줄 추출
- 또는 단순 텍스트 요약

> ❗ LLM 요약은 추후 적용
> 

---

### 5) 디스코드 알림 전송

- Discord Webhook 사용
- 기본 메시지 형태로 전송

예시:

```
[업데이트]

제목: 3/27 업데이트 노트
요약: 신규 콘텐츠 추가 및 오류 수정
링크: https://...
```

---

### 6) 중복 알림 방지

- URL 기준으로 중복 체크
- 이미 전송된 게시글은 제외

---

### 7) 주기 실행

- 5~10분 간격 자동 실행
- APScheduler 사용

---

### 8) 로그 출력

- 콘솔 로그 기반

예시:

```
[INFO] 공지사항 1건 신규 발견
[INFO] 디스코드 전송 완료
```

---

### 3.3 데이터 저장

- SQLite 사용
- 저장 정보:
    - 게시판 종류
    - 제목
    - URL
    - 수집 시간

---

## 9. 완료 기준 (MVP)

다음 조건을 만족하면 MVP 완료로 간주한다.

- 공지 / 업데이트 / 이벤트 게시글 자동 감지
- 신규 글 발생 시 5~10분 내 디스코드 알림
- 동일 게시글 중복 전송 없음
- 시스템이 자동으로 반복 실행됨

> 
- 작게 시작한다
- 안정화 후 확장한다
- 불필요한 기능은 뒤로 미룬다
